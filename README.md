# نظام الصياد — HUNTER SYSTEM

موقع فعالية أنمي متكامل: بوابة دخول، اختبار أنمي، حرب فصائل، قضية جنائية، استراحة المحارب، ولوحة إدارة.

## المتطلبات
- Node.js 18 أو أحدث
- قاعدة بيانات SQLite (مدمجة — لا تحتاج تنصيب)
- بوت تيليجرام (التوكن جاهز في `.env.example`)

## التشغيل المحلي
```bash
npm install
cp .env.example .env
# عدّل .env: كلمة مرور الإدارة + IP_SALT
npm start
